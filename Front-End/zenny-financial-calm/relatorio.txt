Relatório do Projeto Zenny - Sistema de Gestão Financeira

1. Visão Geral

O Projeto Zenny é um sistema de gestão financeira desenvolvido por Carlos Eduardo Martins, Gustavo Henrique Dias Marques e Leandro Palozi. O sistema é composto por uma arquitetura moderna dividida em Front-End e Back-End.

2. Arquitetura do Sistema

2.1 Back-End

Tecnologias Principais:

Next.js (Framework TypeScript/Node.js)

Prisma (ORM)

PostgreSQL (Banco de Dados)

2.2 Front-End

Tecnologias Principais:

React com TypeScript

Vite (Build tool)

TailwindCSS

Radix UI (Componentes de interface)

Supabase (Backend as a Service)
